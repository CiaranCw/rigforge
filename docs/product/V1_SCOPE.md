# V1 Scope — Working Baseline

This is a working baseline. It is not frozen. R1 and later decision gates must confirm or cut it.

## Candidate V1 Core

- Canonical Character
- Canonical Skeleton
- Canonical Motion
- Canonical Manifest
- Asset inspect
- Skeleton inspect
- Motion inspect
- Skeleton validation
- Motion validation
- Semantic Skeleton Mapping
- Skeleton Compatibility
- Deterministic Retarget
- Retarget QC
- At least one real ingest/publish E2E path
- Domain API
- CLI
- Minimal Workbench

## Explicitly Non-Core / Optional

Not V1 foundation. Do not treat as mandatory dependencies:

- AI Retarget
- automatic Foot IK correction
- full AI Auto-rig
- SkinTokens mandatory dependency
- UniRig mandatory dependency
- AnyTop mandatory dependency
- SATA mandatory dependency
- OpenAssetIO mandatory runtime dependency
- AYON mandatory runtime dependency
- ozz as Canonical
- VRM Humanoid as universal schema
- Blender/Maya as mandatory ingest path
- complete DCC replacement
- complete engine asset pipeline replacement
