# Research

Facts for W0 and later research live here. Product intent lives in `docs/product/`. Architecture decisions live in `docs/architecture/`.

## Priority of sources

1. Official specifications
2. Official documentation
3. Official source code
4. Formal papers
5. Community material

## Evidence classification

Mark every material conclusion with one of:

| Tag | Meaning |
| --- | --- |
| `SPEC` | Official specification text |
| `OFFICIAL_DOC` | Official documentation from the owner |
| `SOURCE_CONFIRMED` | Confirmed in official source |
| `PROJECT_CLAIM` | Claimed by a project (README, marketing, issue) without source confirmation |
| `PAPER` | Formal paper |
| `RIGFORGE_INFERENCE` | Our inference, not an upstream fact |

A project README that “supports Retarget” is a `PROJECT_CLAIM`. It is not evidence that the project meets RigForge retarget requirements.
