# Research Sources

Citation index only. Do not download bulk documentation, clone third-party repositories, or vendor source here during W0 unless a later task explicitly requires it.

## Record shape

Each cited source should record:

- Source name
- Source type
- Canonical URL
- Version / release / commit if applicable
- Access date
- Relevant claim
- Evidence classification (`SPEC` / `OFFICIAL_DOC` / `SOURCE_CONFIRMED` / `PROJECT_CLAIM` / `PAPER` / `RIGFORGE_INFERENCE`)

## What to keep

Prefer:

- URL
- version
- commit
- precise finding
- a short excerpt only when legally appropriate and necessary

Do not paste third-party web pages or specification dumps into the repository.
