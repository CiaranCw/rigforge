# rigforge_workbench

Minimal V1-2 Workbench shell using egui/eframe.

This crate is the GUI process. It talks only to `rigforge_app`. It does not
call Blender, select a Preview viewer, or select a Preview payload.

ADR: `docs/architecture/decisions/ADR-0004-v1-workbench-gui.md`
(`Accepted` at V1-2 focused review).
